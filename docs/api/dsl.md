# DSL API (`feature = "query"`)

The typed query DSL lets you write SQL-like queries in Rust with full compile-time column
type checking.  Enable it with `features = ["query", "postgres"]` (or `sqlite`/`mysql`).

---

## Quick start

```toml
[dependencies]
rok-fluent = { version = "0.4", features = ["query", "postgres"] }
```

```rust
use rok_fluent::dsl::db;

#[derive(Debug, sqlx::FromRow, rok_fluent::TableDerive)]
#[table(name = "users")]
pub struct User {
    pub id:    i64,
    pub name:  String,
    pub email: String,
}

// SELECT * FROM "users" WHERE "users"."id" = $1
let user: Option<User> = db::select()
    .from(users::table)
    .where_(users::id.eq(42_i64))
    .fetch_optional::<User>(&pool)
    .await?;
```

---

## `#[derive(Table)]`

Attach to any `sqlx::FromRow` struct.  The macro generates:

1. A `pub mod <table_name>` companion module (behind `#[cfg(feature = "query")]`):
   - `pub const table: TableMarker` — pass to `.from()`, `.insert_into()`, etc.
   - One `pub const <field>: Column<Struct, FieldType>` per non-skipped field.

2. *(Phase 21, coming soon)* Associated constants on the struct itself:
   `User::TABLE`, `User::ID`, `User::NAME`, etc.

### Struct-level attributes

| Attribute | Description |
|---|---|
| `#[table(name = "users")]` | Override the table name (default: snake_case + "s") |

### Field-level attributes

| Attribute | Description |
|---|---|
| `#[table(skip)]` | Exclude this field from column generation |
| `#[table(column = "col_name")]` | Override the SQL column name |

### Example

```rust
#[derive(Debug, sqlx::FromRow, rok_fluent::TableDerive)]
#[table(name = "blog_posts")]
pub struct Post {
    pub id:         i64,
    pub title:      String,
    #[table(column = "body_text")]
    pub body:       String,
    #[table(skip)]
    pub cache_key:  String,  // not a DB column
}

// Generated module:
// pub mod blog_posts {
//     pub const table: TableMarker = TableMarker;
//     pub const id:    Column<Post, i64>    = Column::new("blog_posts", "id");
//     pub const title: Column<Post, String> = Column::new("blog_posts", "title");
//     pub const body:  Column<Post, String> = Column::new("blog_posts", "body_text");
//     // cache_key is skipped
// }
```

## Entry points (`db::`)

```rust
use rok_fluent::dsl::db;

db::select()                   // → SelectBuilder
db::insert_into(table)         // → InsertBuilder
db::update(table)              // → UpdateBuilder
db::delete_from(table)         // → DeleteBuilder
```

## `SelectBuilder`

```rust
db::select()
    .from(users::table)            // set the table
    .columns(["id", "name"])       // restrict columns (default: SELECT *)
    .distinct()                    // SELECT DISTINCT
    .where_(expr)                  // add WHERE predicate (multiple calls are AND-ed)
    .order_by(users::name.asc())   // ORDER BY col ASC/DESC
    .limit(20)                     // LIMIT n
    .offset(40)                    // OFFSET n
```

### PostgreSQL terminals

| Method | SQL | Returns |
|---|---|---|
| `.fetch_all::<T>(&pool)` | `SELECT …` | `Result<Vec<T>>` |
| `.fetch_one::<T>(&pool)` | `SELECT … LIMIT 1` | `Result<T>` (RowNotFound if empty) |
| `.fetch_optional::<T>(&pool)` | `SELECT … LIMIT 1` | `Result<Option<T>>` |
| `.exists(&pool)` | `SELECT EXISTS (…)` | `Result<bool>` |
| `.count(&pool)` | `SELECT COUNT(*) …` | `Result<i64>` |

### SQL rendering (for testing / logging)

```rust
let (sql, params) = builder.to_sql_pg();    // $1, $2, … placeholders
let (sql, params) = builder.to_sql_qmark(); // ? placeholders (SQLite/MySQL)
```

## `InsertBuilder`

```rust
db::insert_into(users::table)
    .values([("name", "Alice"), ("email", "alice@example.com")])
    .execute(&pool).await?;                 // → Result<u64> (rows affected)

// With RETURNING
let user: User = db::insert_into(users::table)
    .values([("name", "Bob"), ("email", "bob@example.com")])
    .returning()
    .fetch_one::<User>(&pool).await?;
```

---

## `UpdateBuilder`

```rust
db::update(users::table)
    .set("name", "Carol")
    .set("email", "carol@example.com")
    .where_(users::id.eq(42_i64))
    .execute(&pool).await?;    // → Result<u64>
```

---

## `DeleteBuilder`

```rust
db::delete_from(users::table)
    .where_(users::id.eq(42_i64))
    .execute(&pool).await?;    // → Result<u64>
```

## `Column<T, V>` methods

All columns generated by `#[derive(Table)]` are `Column<StructType, FieldType>` values.

### Comparison operators (require `V: Into<SqlValue>`)

| Method | SQL |
|---|---|
| `.eq(val)` | `col = $N` |
| `.ne(val)` | `col != $N` |
| `.gt(val)` | `col > $N` |
| `.gte(val)` | `col >= $N` |
| `.lt(val)` | `col < $N` |
| `.lte(val)` | `col <= $N` |
| `.like(pattern)` | `col LIKE $N` |
| `.not_like(pattern)` | `col NOT LIKE $N` |
| `.in_(vals)` | `col IN ($1, $2, …)` |
| `.not_in(vals)` | `col NOT IN ($1, $2, …)` |

### Null checks (no `V: Into<SqlValue>` required)

| Method | SQL |
|---|---|
| `.is_null()` | `col IS NULL` |
| `.is_not_null()` | `col IS NOT NULL` |

### Ordering

| Method | Returns |
|---|---|
| `.asc()` | `OrderExpr` — pass to `.order_by()` |
| `.desc()` | `OrderExpr` |

## `Expr` — composable boolean expressions

```rust
use rok_fluent::dsl::Expr;

// Combine with .and() / .or()
let expr = users::email.like("%@example.com")
    .and(users::id.gt(0_i64))
    .or(users::name.is_not_null());

// Negate with !
let not_deleted = !posts::deleted_at.is_not_null();

// Nest freely
let complex = (users::id.gt(10_i64).and(users::id.lt(100_i64)))
    .or(users::email.eq("admin@example.com"));
```

Rendered SQL:
```sql
(("users"."id" > $1 AND "users"."id" < $2) OR "users"."email" = $3)
```

## `SqlValue` types

`Column<T, V>` accepts any type implementing `Into<SqlValue>`.

| Rust type | `SqlValue` variant |
|---|---|
| `&str`, `String` | `Text(String)` |
| `i8`, `i16`, `i32`, `i64`, `u32`, `u64` | `Integer(i64)` |
| `f32`, `f64` | `Float(f64)` |
| `bool` | `Bool(bool)` |
| `serde_json::Value` | `Json(Value)` |
| `uuid::Uuid` | `Uuid(Uuid)` |
| `Option<T>` where `T: Into<SqlValue>` | `Null` when `None`, inner value when `Some` |

## Combining DSL with Active Record (requires `active` + `query`)

// Use a typed Expr inside a ModelQuery:
let posts = Post::query()

    .get().await?;

## Relationship loading (coming in Phase 23)

```rust
// Declare relationships on the struct:
#[derive(Table)]
#[table(name = "users")]
pub struct User {
    pub id:   i64,
    pub name: String,

    #[table(has_many = Post, fk = "user_id")]
    pub posts: Loaded<Vec<Post>>,

    #[table(belongs_to = Organization, fk = "org_id")]
    pub organization: Loaded<Option<Organization>>,
}

// Load them in queries:
let users: Vec<User> = db::select()
    .from(users::table)
    .with(users::posts)
    .with(users::organization)
    .fetch_all(&pool)
    .await?;

// Access:
for user in &users {
    for post in user.posts.get().unwrap() {
        println!("{}: {}", user.name, post.title);
    }
}
```
